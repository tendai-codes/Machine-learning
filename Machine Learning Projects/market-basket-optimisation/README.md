# Market Basket Optimisation

## Project Description
This repository contains market basket analysis notebooks using Apriori and Eclat for association rule mining.

## Contents
- `Market basket optimisation_Apriori.ipynb`
- `Market basket optimisation _Eclat.ipynb`
- `Market_Basket_Optimisation.csv`

## Run
1. Install requirements from `requirements.txt`.
2. Open notebooks in Jupyter.
3. Ensure `Market_Basket_Optimisation.csv` is in this folder.
