# Customer Segmentation

## Project Description
This repository contains customer segmentation notebooks using K-Means and Hierarchical Clustering on mall customer data.

## Contents
- `Customer Segmentation_K means Clustering.ipynb`
- `Customer Segmentation_Hierarchical Clustering.ipynb`
- `Mall_Customers.csv`

## Run
1. Install requirements from `requirements.txt`.
2. Open notebooks in Jupyter.
3. Ensure `Mall_Customers.csv` is in this folder.
