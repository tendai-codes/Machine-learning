# Customer Segmentation Using K-Means and Hierarchical Clustering

## Problem

This project analysed customer purchasing behaviour data to identify distinct customer segments that could support targeted marketing strategy and customer profiling.

## Objective

- Explore structure within customer behavioural data using unsupervised learning techniques
- Apply clustering methods to identify natural groupings of customers
- Compare segmentation behaviour between hierarchical clustering and K-Means clustering
- Support interpretation of customer segments using visual cluster representations

## Approach

- Selected relevant customer behavioural variables for segmentation analysis
- Applied hierarchical clustering to determine cluster structure using dendrogram visualisation
- Implemented K-Means clustering to partition customers into distinct groups
- Visualised cluster assignments to examine differences between customer segments

## Key Findings

- Dendrogram visualisation from hierarchical clustering indicated an appropriate cluster structure that guided selection of the number of customer segments
- K-Means clustering produced segment assignments consistent with the cluster structure suggested by the dendrogram
- Both clustering approaches identified comparable group separation patterns across customer spending attributes
- Visual cluster plots enabled side-by-side inspection of segmentation structure produced by hierarchical clustering and K-Means
